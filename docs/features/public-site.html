Public site

Four public routes, all client-rendered, all fed by the JSON API.

Routes

Route Component What it does
/web/src/pages/Home.tsxTheme hero (profile, post count, tag count), the 3 newest published posts, tag cloud
/blogBlog.tsxFull archive, 10 per page, tag filter and pager driven by ?tag= and ?page=
/blog/:slugPostReader.tsxOne post inside the theme's ReaderChrome, body rendered as Markdown
/aboutAbout.tsxAvatar, name, headline, location, bio paragraphs, skills, external links
*NotFound.tsx404 panel with a link home

Home page

One Promise.all([getProfile(), listPosts({perPage: 3}), getTags()]) populates everything. postCount comes from meta.total (all published posts, not the three shown) and tagCount is the length of the tag list. If any of the three requests fails, the whole page renders ErrorState with the API's message; while they are in flight it renders a spinner (LoadingState).

Blog archive

  • Page size is fixed at 10 in the frontend call; the API accepts per_page up to 100.
  • The tag filter writes ?tag=ruby into the URL, so a filtered archive is shareable and survives reload. Selecting a tag resets pagination (the params object is replaced, not merged).
  • Pager buttons appear only when meta.total_pages > 1; «Newer» is disabled on page 1 and «Older» on the last page.
  • A non-numeric or negative ?page= falls back to 1 on both sides.
  • A failed tag request shows its own inline error without blanking the post list.

Post reader

GET /api/v1/posts/:slug is called without a token, so an unpublished post 404s here even if you are logged in in another tab — previewing a draft happens in the editor. The body is Markdown with GFM tables and highlighted code blocks; the surrounding chrome (cover image, date, reading time, tags, back link) is supplied by the active theme.

Shared UI states

web/src/components/States.tsx has exactly two: a spinner with a “Loading…” label and an error panel that shows the message and, when a retry callback is given, a “Try again” button. Error text comes from the API's error field, or the generic “Something went wrong. Please try again.” when the response has no message.

Asset URLs

resolveAssetUrl() leaves absolute URLs alone and prefixes relative ones with API_URL. That is why the seeded covers (/covers/sunset.svg) and the avatar (/covers/avatar.svg) resolve against the Rails app, which serves them from api/public/covers/.

Reading time

Computed server-side in Post#reading_time_minutes: whitespace-separated words divided by 200, rounded up, minimum 1. It is part of every serialized post, so all themes show the same number.
