RSS feed

/feed.xml is hand-rendered RSS 2.0 straight from the API, with the 20 newest published posts.

Endpoint

GET /feed.xml → FeedController#show, routed with defaults: { format: :xml }. It is public and takes no parameters. The frontend exposes it as RSS_URL (${API_URL}/feed.xml) in theme footers.

What it contains

  • Channel title Karol's Engineering Blog, description Notes on software engineering by Karol., link = SITE_URL, and a lastBuildDate of “now”.
  • Post.published.limit(20) — newest by published_at, drafts excluded.
  • Per item: title, full body as HTML inside <description>, pubDate (published_at, falling back to created_at, in RFC 2822), and guid/link = <SITE_URL>/blog/<slug>.

Markdown and safety

Redcarpet::Markdown.new(Redcarpet::Render::HTML.new(hard_wrap: true, filter_html: true))
  • This is the only place the server turns Markdown into HTML.
  • filter_html: true strips raw HTML, so a <script> in a post body never reaches a reader's client.
  • Titles and links are escaped with CGI.escapeHTML; bodies are wrapped in CDATA with any ]]> inside them split safely (]]> → ]]]]><![CDATA[>). Both behaviours have tests, including a unit test on the cdata helper itself.

SITE_URL matters here

Every link and guid is built from ENV.fetch("SITE_URL", "http://localhost:5173") with a trailing slash chomped. If you ever publish the feed, set SITE_URL to the public site origin — otherwise subscribers get localhost links, and because the guid is derived from the same value, changing it later re-announces every item as new.

Shape

<?xml version="1.0" encoding="UTF-8"?>
<rss version="2.0">
  <channel>
    <title>Karol&#39;s Engineering Blog</title>
    <description>Notes on software engineering by Karol.</description>
    <link>http://localhost:5173</link>
    <lastBuildDate>Mon, 31 Aug 2026 06:00:00 +0000</lastBuildDate>
    <item>
      <title>The Boring Parts of a Good Rails Application</title>
      <description><![CDATA[<h2>Boring is a feature</h2>...]]></description>
      <pubDate>Sat, 01 Aug 2026 09:12:00 +0000</pubDate>
      <guid isPermaLink="true">http://localhost:5173/blog/the-boring-parts-of-a-good-rails-application</guid>
      <link>http://localhost:5173/blog/the-boring-parts-of-a-good-rails-application</link>
    </item>
  </channel>
</rss>

There is no caching or conditional-GET support: every request re-renders all 20 bodies through Redcarpet.
