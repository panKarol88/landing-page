Four themes

Notion, Brutalist, Pixel, and Neon are complete component sets, not colour palettes.

How a theme is selected

  1. web/index.html runs a tiny inline script before React boots: it reads localStorage.theme, validates it against the four ids, and sets document.documentElement.dataset.theme. This is what prevents a flash of the default theme.
  2. ThemeProvider repeats that validation in React state, writes the choice back to localStorage, and updates the <meta name="theme-color"> tag (#ffffff, #0a0a0a, #2b1b6b, #05060a).
  3. Pages call useTheme() and destructure the components they need, so no page contains theme-specific markup.

The contract

web/src/themes/registry.ts requires every theme to export six components:

Component Props Used by
Shell{ children, profile? }PublicLayout — header, nav, theme switcher, footer
Hero{ profile, postCount, tagCount }Home
TagCloud{ tags, activeTag?, onSelect? }Home (read-only) and Blog (interactive)
PostList{ posts }Home and Blog
PostCard{ post, index? }Inside each theme's own list
ReaderChrome{ post, children }Post reader

The token system

web/src/styles/themes.css defines one variable block per [data-theme="…"]; web/tailwind.config.js maps Tailwind names onto those variables. Writing bg-surface text-fg border-border rounded-theme shadow-card therefore produces different visuals per theme with identical markup.

Also tokenised: --space-section (py-section) and the three font sizes hero, page-title, section-title, several of which use clamp() so the loud themes scale with the viewport. The typography plugin's prose colours are re-pointed at the same variables, which is why rendered Markdown always matches the theme.

The switcher

ThemeSwitcher.tsx is a small listbox: aria-haspopup/aria-expanded on the button, role="option" with aria-selected on each item, arrow-key navigation, Enter to choose, Escape and outside-click (a mousedown listener on document) to close.

Adding a fifth theme

  1. Create web/src/themes/<id>/index.tsx exporting the six components.
  2. Add a [data-theme="<id>"] variable block to web/src/styles/themes.css.
  3. Add the id to THEME_IDS, a label to THEME_LABELS, and the components to registry.
  4. Add its background colour to themeColors in ThemeProvider.tsx and to the bootstrap array in web/index.html — miss the second one and a reload briefly shows Notion.
