Home

Documentation home

The official, internal documentation for the landing-page repository — a personal blog made of a Rails 8 JSON API and a Vite + React frontend with four swappable themes.

This site is generated from the code in this repository, not from memory: every route, environment variable, and default below was read out of api/, web/, and docker-compose.yml. It is plain HTML with one stylesheet and inline JavaScript, so it works when you open docs/index.html straight from disk — no server, no build.

The system in one paragraph

PostgreSQL stores one interesting table, posts. A Rails 8 API-only app exposes it as JSON under /api/v1, renders an RSS feed at /feed.xml, and protects every write with a single-password login that hands back a 7-day HS256 JWT. A React single-page app calls that API with fetch, renders Markdown in the browser, and paints everything through one of four complete visual themes chosen from the header. Uploads are stored on disk by Active Storage. Development runs as three Docker services (db, api, web) or natively via bin/dev.

How to read these pages

  • The sidebar lists every page; the filter box at its top narrows it by title.
  • Code blocks have a Copy button; the right column is a per-page table of contents.
  • The Dark mode button in the header is remembered in localStorage.
  • Every link is relative, so the whole folder can be moved, zipped, or synced anywhere.

Audience: you, the only author and operator of this site. So the pages state passwords, token internals, and failure modes plainly rather than hiding them.
