CI, tests & linters

GitHub Actions covers the API. The frontend is linted but has no test runner.

GitHub Actions

api/.github/workflows/ci.yml runs on every pull request and on pushes to main, with three jobs:

Job Steps Notes
scan_rubybin/brakeman --no-pager, bin/bundler-auditStatic security analysis and a gem CVE audit
lintbin/rubocop -f githubCached via actions/cache keyed on .ruby-version, rubocop config, and Gemfile.lock
testbin/rails db:test:prepare testPostgres service container, DATABASE_URL=postgres://postgres:postgres@localhost:5432, installs libpq-dev libvips

The workflow lives inside api/, so GitHub picks it up from api/.github/workflows/ only if that directory is at the repository root for the checkout in question. In this monorepo the workflow file is committed under api/ — worth verifying in the Actions tab before relying on it as a merge gate. Dependabot config sits next to it.

The local pipeline

api/bin/ci uses ActiveSupport::ContinuousIntegration and is the fuller gate:

step "Setup",                            "bin/setup --skip-server"
step "Style: Ruby",                      "bin/rubocop"
step "Security: Gem audit",              "bin/bundler-audit"
step "Security: Brakeman code analysis", "bin/brakeman --quiet --no-pager --exit-on-warn --exit-on-error"
step "Tests: Rails",                     "bin/rails test"
step "Tests: Seeds",                     "env RAILS_ENV=test bin/rails db:seed:replant"

Note the extra seed step: it proves db/seeds.rb still runs cleanly from scratch.

Frontend quality

Command What it does
npm run lintESLint over ts,tsx with --max-warnings 0, TypeScript + react-hooks + react-refresh rules, Prettier compatibility
npm run formatPrettier writes src/
npm run buildtsc -b then vite build — the de facto type check

There is no frontend test runner (no Vitest, no Playwright) and no CI job for web/. Frontend regressions are caught by npm run build, lint, and clicking around. That is the biggest gap in the quality setup.

Ruby style

api/.rubocop.yml inherits rubocop-rails-omakase — the Rails-team defaults, deliberately unopinionated about line length. Autocorrect with bin/rubocop -a.
