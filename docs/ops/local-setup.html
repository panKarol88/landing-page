Native local setup

Running the stack without Docker: Ruby 3.3.6, PostgreSQL, Node, and bin/dev.

When to bother

Docker is the documented default. Native is worth it for a faster edit–test loop, a debugger attached to Puma, or when Docker is unavailable. The canonical instructions live in scripts/setup.md; this page summarises them and adds the details that matter afterwards.

1. Ruby 3.3.6

Ubuntu 22.04's apt Ruby is 3.0, so scripts/setup.md builds 3.3.6 from source into ~/.rubies/ruby-3.3.6 and prepends it to PATH. Build dependencies: build-essential autoconf bison libssl-dev libyaml-dev libreadline-dev zlib1g-dev libncurses5-dev libffi-dev libgdbm-dev libdb-dev uuid-dev rustc cargo. Then gem install rails -v '~> 8.1' --no-document.

2. PostgreSQL

sudo apt-get install -y postgresql postgresql-contrib libpq-dev
sudo pg_ctlcluster 14 main start
sudo -u postgres createuser --superuser "$USER"   # skip if the role exists

api/config/database.yml has no host/username for development, so Rails connects over the local Unix socket as your OS user — no password needed. Databases: api_development and api_test.

3. API

cd api
bundle install
cp .env.example .env      # then set ADMIN_PASSWORD and JWT_SECRET
bin/rails db:create db:migrate db:seed
bin/rails server -p 3000

dotenv-rails loads api/.env in development and test. Uploads go to api/storage/ via the Active Storage local disk service.

4. Frontend

cd web
npm install
npm run dev            # vite --host 0.0.0.0, port 5173

web/.env.example documents the only variable, VITE_API_URL (default http://localhost:3000). Vite only exposes variables prefixed VITE_, and they are baked in at build time.

5. Both at once

bin/dev      # from the repo root

bin/dev starts bin/rails server -p 3000 and npm run dev in parallel, and traps INT/TERM/EXIT so Ctrl+C stops both. It also hard-codes PATH="/home/ubuntu/.rubies/ruby-3.3.6/bin:$PATH", which matches scripts/setup.md but must be edited if your Ruby lives elsewhere. Procfile.dev describes the same two processes for any Procfile runner (foreman, overmind).

Useful native commands

Goal Command
Full quality pipelinecd api && bin/ci
Tests onlycd api && bin/rails test
Ruby stylecd api && bin/rubocop (-a to autocorrect)
Security scansbin/brakeman, bin/bundler-audit
Reset the databasecd api && bin/rails db:reset
Frontend lint / formatcd web && npm run lint / npm run format
Type-check + production buildcd web && npm run build

Docker and native can share nothing safely: both want ports 3000/5173 and the same database name. Stop one before starting the other.
