Infrastructure

  • PostgreSQL 16 (postgres:16-alpine) with a pg_isready healthcheck the API waits on.
  • Node 20 (node:20-slim) for the web container.
  • GitHub Actions for the API only: scan_ruby, lint, test (see CI).
  • Active Storage disk service — local in development, test writes to api/tmp/storage.

Fonts and assets

The app's web/index.html pulls Inter, JetBrains Mono, Press Start 2P, Space Grotesk, and VT323 from Google Fonts. That is the app's only external dependency at runtime; these documentation pages deliberately use none.
