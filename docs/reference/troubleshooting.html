Troubleshooting

Symptoms, causes, and fixes — ordered by how often they happen.

Startup

Symptom Likely cause Fix
Frontend loads but every panel shows an errorAPI not ready yet (it migrates and seeds on boot) or not runningWatch docker compose logs -f api; check curl http://localhost:3000/up
bind: address already in useSomething already on 3000 or 5173 — often a native run plus DockerStop the other process (lsof -i :3000)
API exits with a Postgres connection errordb not healthy yet, or a stale db-data volumedocker compose up waits on the healthcheck; if it persists, docker compose down -v
bundle or npm ci runs on every startGemfile.lock / package-lock.json changed, or the named volume was removedExpected once; then it is cached
Native bin/dev cannot find RubyIt hard-codes /home/ubuntu/.rubies/ruby-3.3.6/binEdit bin/dev or match the path from scripts/setup.md

Authentication

Symptom Likely cause Fix
“Invalid password” with the right passwordADMIN_PASSWORD not reaching the API containerdocker compose exec api env | grep ADMIN, then recreate the service
500 on POST /api/v1/sessionJWT_SECRET unset — Api::Security.jwt_secret raisesSet it and restart
Logged in, then instantly bounced to the login pageToken expired (7 days) or JWT_SECRET changedSign in again
“Too many login attempts”10 attempts within 3 minutesWait, or restart the API (the limiter uses the in-memory cache)
Admin screens visible but every request 401sA junk admin_token in localStorage; the frontend guard only checks presenceSign out, or clear the key in devtools

Posts and content

Symptom Likely cause Fix
A new post is not on /blogStill a draftPublish it from the dashboard or with published: true
A post 404s at its URLDraft, or the slug was renamedCheck the dashboard; old slugs are not redirected
Publishing does not move the post to the toppublished_at was set on the first publish and is never overwrittenClear it via update_columns(published_at: nil) and republish
Local edits to a seeded post reappeardb:seed runs on every Docker boot and re-assigns seeded posts by titleRename the title, or delete the entry from db/seeds.rb
Tag appears twice with different casesOnly the editor lowercases tags; console writes bypass thatNormalise with a bin/rails runner one-liner
422 with no useful message in the UIThe frontend only reads payload.error, while validation errors come back under errorsLook at the network tab or repeat the call with curl

Uploads and images

Symptom Likely cause Fix
“File must be an image” on a real imageFormat outside PNG/JPEG/GIF/WebP — SVG is rejected deliberatelyConvert to PNG or JPEG
“File is too large”Over the 5 MB capResize, or raise MAX_SIZE in UploadsController
Cover image broken after moving hostsUpload URLs are absolute, built from request.base_urlRe-upload, or rewrite cover_image_url values
Uploads disappeareddocker compose down -v removed the api-storage volumeRestore from a backup of api/storage

Frontend

Symptom Likely cause Fix
CORS error in the consoleOrigin is not localhost:5173 / 127.0.0.1:5173Use those origins, or add yours to api/config/initializers/cors.rb
Requests go to the wrong hostVITE_API_URL is baked in at build timeSet it and restart the Vite server / rebuild
Fonts look wrong offlineGoogle Fonts unreachable — the app loads them from the CDNExpected; the layout falls back
Theme flashes on reloadThe bootstrap script in web/index.html does not know the theme idAdd the id to its array as well as to the registry
Blank page after an editA TypeScript/runtime errorCheck the Vite terminal output and the browser console; npm run build type-checks

Docs site

Symptom Cause Fix
Pages are unstyleddocs/assets/docs.css was moved or not copiedKeep the folder structure intact
Dark mode is not rememberedSome browsers block localStorage for file://Harmless — the toggle still works per page
Copy button does nothingClipboard API needs a secure context; the fallback uses execCommandSelect and copy manually

Escape hatch

docker compose down -v          # wipe database and uploads
docker compose up --build       # rebuild, migrate, reseed from scratch

That returns the whole system to the seeded 14-post state in a couple of minutes.
